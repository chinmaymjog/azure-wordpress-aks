# Security Policy

This repository builds container images and a Helm chart for a WordPress
deployment on AKS, plus scripts that handle database and storage credentials.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting:
<https://github.com/chinmaymjog/azure-wordpress-aks/security/advisories/new>

Never include passwords, connection strings, keys, database dumps or real
hostnames in issues or pull requests; use redacted values.

You can expect an initial response within a few days.

## Supported versions

Only the latest `main` receives security fixes.
